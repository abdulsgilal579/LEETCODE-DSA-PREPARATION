## Setup

```bash
# Clone the repo
git clone <repo-url>
cd LeetCode-DSA-Problems-Interview-Prep

# Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Run any solution
python3 LinkedList/Easy/reverseLinkedList.py
```
